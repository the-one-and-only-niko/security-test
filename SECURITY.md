# Security Policy

## Supported versions
| Version | Supported |
|---------|-----------|
| 2.4.x   | ✅        |
| < 2.0   | ❌        |

## Reporting a vulnerability
Email security@meridian-desk.io with details. We aim to triage within 3 business
days. Please do not open public issues for suspected vulnerabilities.

`services/report-service/`, and the `utils/` helpers — were signed off with **no
open findings**.
